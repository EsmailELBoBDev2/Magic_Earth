# v22.3.3 CI hotfix

- Fixes `frida-compile` TS-1 module resolution by staging `search-core.mjs`, `nav-core.mjs`, and `traffic-core.mjs` beside the temporary agent entry file.
- Stops embedding Google Places/Routes keys in APK/AAB. Keys are provisioned after install via `provision_google_key.sh` and migrated into app-private SharedPreferences.
- Keeps future-aware preflight: exact binary-only tweaks run only on the analyzed 7.1.26.26 `libapp.so`; structurally compatible future APKs skip exact offsets and use fail-open runtime/API hooks.
- Future APK support remains compatibility-based, never guaranteed.
