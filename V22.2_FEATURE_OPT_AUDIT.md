# CairoDrive v22.3 — final feature / optimization audit

Decision rule: keep only behavior that improves normal passenger-car use in Cairo without duplicating Magic Earth navigation, fabricating road-width evidence, or adding unbounded API/runtime cost.

| Area | v22.3 decision | Implementation |
|---|---|---|
| Google Places primary + native fallback | **KEEP** | Google for high-quality POI/address discovery; native Magic Earth for offline/failure/unmapped cases. |
| Nearby categories / Autocomplete / Text Search | **KEEP** | Precise Google types where safe; native fallback where semantics are ambiguous. |
| Search Along Route | **KEEP** | Remaining Magic Lane polyline only; route-aware POIs ranked by traffic-aware via-stop cost. |
| Navigation points / entrances | **KEEP** | Prefer actual driving navigation point / unambiguous mapped entrance over centroid. |
| Magic Lane routing authority | **KEEP** | No Google route is rendered or navigated. |
| Magic Lane online traffic | **KEEP** | Native traffic feeds native route quality and better-route detection. |
| Initial online calculation | **FAIL-OPEN KEEP** | Set `allowOnlineCalculation=true` only if exact target wrapper exposes it and network exists. Active reroutes preserve stock/request state. |
| Google traffic advisory | **KEEP** | Geometry/heading/coverage validated; 3-level policy below. |
| Level 1 traffic | **KEEP CURRENT ROUTE** | No roadblock; avoid needless churn. |
| Level 2 traffic | **NATIVE DECISION** | Let Magic Lane better-route logic evaluate; suggest/auto-switch only for meaningful savings and route-quality context. |
| Level 3 traffic | **AVOID** | Strong contiguous meaningful jam can create temporary native roadblock; Magic Lane computes replacement. |
| Strong SingleTrack/Path evidence | **AVOID WHEN UPCOMING** | Native temporary roadblock; no guessing width from residential/classification labels. |
| Candidate alternative contains SingleTrack/Path | **DO NOT AUTO-SWITCH** | Keep current route / leave candidate to stock user choice. |
| Candidate narrow quality unknown during a narrow escape | **DO NOT BLIND AUTO-SWITCH** | Stock suggestion only. |
| Fastest + avoidTraffic=All | **KEEP** | Core native routing policy. |
| Avoid unpaved | **KEEP** | Normal passenger-car comfort choice for this build. |
| Departure heading / waypoint approach | **KEEP** | Low-risk routing/arrival quality improvement. |
| Terrain profile | **INITIAL ONLY** | Needed for narrow evidence; disabled on active reroutes for latency. |
| Fake 200cm truck width | **REMOVED** | Vehicle dimension is not a comfort proxy. |
| Forced U-turn avoidance | **REMOVED** | Could suppress legitimate routing instructions. |
| Redundant route-default rewrites | **REMOVED** | Preserve Magic Lane defaults; smaller ABI mutation surface. |
| Initial alternatives | **STOCK** | Preserve normal route-choice quality. |
| Active-reroute alternatives | **NEVER** | Need one replacement route quickly; avoid fan-out. |
| `ExternalCh` | **EXPERIMENT ONLY** | Exists on target, but no public guarantee of faster/equivalent behavior. Production remains MagicEarth. |
| Custom navigation overlay | **SUPPLEMENTAL ONLY** | Magic Earth owns normal turn/lane/ETA UI. CairoDrive shows only extra traffic/narrow/restriction/arrival/status context. |
| Report / Pause / Repeat controls | **ONE COMPACT MENU** | Same QoL, less map obstruction. |
| Google query gate | **3 codepoints** | Allows short names such as KFC/ATM while 400ms debounce/cancellation protects request volume. |
| Details fields | **TYPE-ADAPTIVE** | Expensive restaurant/fuel/parking/lodging fields only where relevant. |
| Traffic-aware Nearby ranking | **NAVIGATION ONLY** | Worth the extra routing-summary cost while driving, not casual browsing. |
| Safety/social sources | **RESPECT STOCK STATE** | No forced enablement; dynamic current-country report categories. |
| HTTP polling | **~100ms** | Fewer wakeups, negligible network/UI latency change. |
| Diagnostics | **THROTTLED / FIRST-TEST** | Needed for ABI and recompute proof; reduce after stability is proven. |

## Better-route thresholds

| Context | Stock/supplemental suggestion | CairoDrive auto-switch |
|---|---:|---:|
| Normal | >= 120 s gain | >= 300 s gain |
| Level-2 traffic | >= 60 s gain | >= 180 s gain |
| Narrow-road context | >= 60 s gain | >= 120 s gain |
| Level-2 + narrow | >= 60 s gain | >= 90 s gain |
| Level-3 jam | native roadblock/recompute first | >= 120 s only if a better-route callback separately arrives and candidate quality passes |

Auto-switch is always cancelled if Magic Lane invalidates the proposal. Candidate strong narrow/path evidence vetoes CairoDrive auto-switch.

## Recompute target

Goal: driver-visible route recompute **under 1,000 ms when possible**.

Optimizations shipped:

- corrected roadblock distance-ahead semantics;
- no terrain-profile build during active reroute;
- no alternative-route fan-out during active reroute;
- cancel stale Google traffic advisory work on native recompute;
- 40 ms CairoDrive fallback after stock better-route callback;
- exact target status/update instrumentation plus trigger-to-route E2E timing.

Not shipped merely to win a benchmark:

- forcing local-only routing without proof maps are available;
- lowering route result quality required for navigation;
- disabling native traffic avoidance;
- blindly switching to `ExternalCh`;
- CPU/thread/GL scheduling hacks.

A sub-second claim is valid only after device logs show it across representative Cairo reroutes.
